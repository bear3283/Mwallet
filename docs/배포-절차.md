# 배포 절차

App Store 에 처음 내보내기까지의 순서입니다. 레인으로 할 수 있는 것과
대시보드에서만 되는 것을 갈라 두었습니다.

> 코드 쪽 준비는 끝나 있습니다. 아래 1번은 이미 되어 있고, 2번부터가 남은 일입니다.

<br>

## 1. 코드·프로젝트 (완료)

| 한 일 | 자리 |
|---|---|
| 개인정보 매니페스트 | `Mwallet/PrivacyInfo.xcprivacy`, `MwalletWidget/PrivacyInfo.xcprivacy` |
| 쓰지 않는 entitlement 삭제 | `Mwallet/Mwallet.entitlements` |
| 버전 `1.0.0` | `MARKETING_VERSION` 여덟 자리 |
| 위젯 기기 패밀리를 앱과 맞춤 | `TARGETED_DEVICE_FAMILY = 1` |
| 스크린샷 기기를 6.9인치로 | `fastlane/Fastfile` 의 `SCREENSHOT_DEVICE` |
| 스크린샷 업로드 레인 | `fastlane screenshots_upload` |

**개인정보 매니페스트를 왜 넣었나** — Apple 이 '사유를 적어야 하는 API' 로 정해 둔
것을 쓰면서 적지 않으면, 올린 직후 ITMS-91053 메일이 오고 심사에서 되돌아옵니다.
이 앱이 걸리는 것은 `UserDefaults` 하나이고(환율 캐시·첫 실행 표시·위젯과 나눠 쓰는
App Group 묶음), 파일 시각·남은 용량·기기 가동 시간 API 는 쓰지 않습니다.
**확장도 제 것을 따로 내야 합니다** — 검사는 번들마다 돕니다.

**entitlement 를 왜 뺐나** — `background-tasks.continued-processing.gpu` 가 적혀
있었는데 코드 어디에서도 쓰지 않습니다. App ID 에 켜 두지 않은 권한이 적혀 있으면
아카이브를 내보낼 때 프로비저닝 프로파일이 맞지 않는다며 막힙니다.

<br>

## 2. 푸시

`origin/main` 이 한참 뒤에 있으면 배포한 것과 저장소에 있는 것이 달라집니다.

```bash
git push origin main
```

<br>

## 3. 열쇠와 앱 확인

```bash
bundle exec fastlane check_key
```

볼 수 있는 앱 목록에 `com.bear3745.Mwallet.app` 이 나와야 합니다. 없으면
[App Store Connect](https://appstoreconnect.apple.com) 에서 앱을 먼저 만드세요 —
이름·SKU·번들 ID 를 정하는 일이라 레인이 대신하지 않습니다.

> `.p8` 개인키는 iCloud Drive 밖에 두는 편이 좋습니다. iCloud 는 용량이 모자라면
> 로컬 사본을 비우는데, 그러면 배포하려는 날 키가 없습니다.
> `~/.appstoreconnect/private_keys/` 가 무난한 자리이고, 옮겼으면
> `fastlane/.env` 의 `ASC_KEY_PATH` 도 함께 고치세요.

<br>

## 4. TestFlight

```bash
bundle exec fastlane beta
```

레인이 순서대로 합니다 — 테스트 405건 → 린트 → 빌드 번호 올리기 → 아카이브 →
업로드. 깨진 것을 올려 놓고 알아채면 늦으므로 앞의 둘을 먼저 돌립니다.

첫 아카이브에서는 이 둘을 눈으로 확인하세요.

- `.ipa` 안의 `aps-environment` 가 `production` 인지 (아카이브할 때 Xcode 가
  바꿔 줍니다. 파일에는 `development` 로 적혀 있는 것이 정상입니다)
- 앱과 위젯 양쪽에 `PrivacyInfo.xcprivacy` 가 들어갔는지

<br>

## 5. 실기기 검증

시뮬레이터에서 안 잡히는 것들입니다.

- **녹음** — 시뮬레이터는 마이크 입력이 없어 `installTap` 이 아예 불리지 않습니다.
  눌러서 말하고 놓는 것까지 해 보세요
- **CloudKit** — 같은 iCloud 계정으로 두 대에 깔고, 한쪽에서 적은 것이 다른 쪽에
  오는지
- **위젯** — 홈 화면에 얹고 눌러 담기, 그 여행의 통화로 적히는지

<br>

## 6. 스크린샷

```bash
bundle exec fastlane store_screenshots     # 열한 언어, 20~30분
bundle exec fastlane screenshots_upload
```

언어마다 시뮬레이터를 비우고 새로 깔며 도는 일이라 오래 걸립니다. 한 언어만
다시 찍으려면 `store_screenshots locale:ja` 처럼 줍니다.

<br>

## 7. 글

```bash
bundle exec fastlane metadata
```

`fastlane/metadata/` 아래 열한 언어가 그대로 올라갑니다.

> **심사 연락처에 전화번호가 없습니다.** `metadata/review_information/phone_number.txt`
> 가 비어 있으면 레인이 연락처를 통째로 건너뜁니다(번호 없이 올리면 Apple 이 거절해서
> 그렇게 해 두었습니다). 번호를 넣으면 이름·메일과 함께 올라갑니다.

<br>

## 8. 대시보드에서만 되는 것

레인으로 안 되는 것들입니다. **첫 번째가 없으면 제출 버튼이 열리지 않습니다.**

- **앱 개인정보(App Privacy)** — 무엇을 모으는지 신고합니다. 이 앱은 기록을 기기와
  사용자 본인의 iCloud 에만 두므로 Apple 이 말하는 '수집' 에 해당하는 것이 없습니다.
  위치·사진·음성도 기기 안에 남고 만든 사람에게 오지 않습니다
- 연령 등급
- 가격과 출시 국가
- 콘텐츠 권리
- 수출 규정 — `ITSAppUsesNonExemptEncryption = NO` 가 빌드 설정에 있어 매번 묻지
  않습니다

<br>

## 9. CloudKit 스키마 승격

```
CloudKit Dashboard → iCloud.com.Mwallet.app → Schema
→ Deploy Schema Changes → Deploy to Production
```

**이걸 빼먹으면 출시된 앱에서 동기화가 조용히 실패합니다.** 개발 환경에 올린
스키마는 운영 환경에 없습니다. 되돌릴 수 없으니(한 번 올라간 필드는 못 지웁니다)
모델이 굳은 지금 하는 것이 맞습니다. 자세한 것은
[`CloudKit-활성화.md`](CloudKit-활성화.md).

<br>

## 10. 심사 제출

TestFlight 빌드를 고르고 제출합니다.

심사 메모(`metadata/review_information/notes.txt`)에 적어 둔 대로, 앱을 처음 열면
예시 여행과 지출이 들어 있어 계정 없이 모든 화면을 볼 수 있습니다.
