# 개인정보처리방침

**Mission Wallet**

시행일: 2026년 8월 13일

---

Mission Wallet(이하 '앱')은 여행과 단기사역 중의 지출을 남기고 정산하는 앱입니다. 이 방침은 앱이 어떤 정보를 다루고 어디에 두는지를 적은 것입니다.

## 한 줄 요약

**앱이 다루는 모든 기록은 사용자의 기기와 사용자 본인의 iCloud에만 있습니다. 개발자는 그 내용을 볼 수 없고, 어디에도 보내지 않으며, 광고나 분석 도구를 넣지 않았습니다.**

## 1. 앱이 다루는 정보

모두 사용자가 직접 넣은 것이며, 별도의 회원가입이나 로그인은 없습니다.

| 무엇 | 언제 생기나 |
|---|---|
| 지출 내역 — 금액·통화·상호명·분류·메모·결제 수단·날짜 | 사용자가 기록할 때 |
| 여행 정보 — 여행 이름·기간·동행자로 적은 이름 | 사용자가 여행을 만들 때 |
| 영수증 사진 | 사용자가 사진을 붙일 때 |
| 지출한 곳의 위치 좌표 | 사용자가 위치 권한을 허용하고 기록할 때 |
| 음성 | 녹음 버튼을 누르고 있는 동안에만 |

동행자 이름은 정산에서 몫을 나누는 데만 쓰이며, 사용자가 적은 글자 그대로 기기에 남습니다. 다른 사람의 연락처를 읽거나 그 사람에게 무언가를 보내는 기능은 없습니다.

## 2. 정보를 두는 곳

**기기 안**이 기본입니다. 앱의 기록은 기기의 저장 공간에 담깁니다.

**iCloud 동기화를 켜면** 같은 Apple 계정의 다른 기기에서도 볼 수 있도록 **사용자 본인의 iCloud 개인 데이터베이스(private database)** 에 함께 저장됩니다. 이는 Apple이 제공하는 사용자 소유의 공간이며, **개발자는 그 안을 들여다볼 권한이 없습니다.** iCloud에 저장된 정보는 [Apple의 개인정보 정책](https://www.apple.com/legal/privacy/kr/)을 따릅니다.

개발자가 운영하는 서버는 없습니다. 사용자의 기록이 개발자에게 전송되는 경로 자체가 없습니다.

## 3. 바깥으로 나가는 통신

앱이 외부와 주고받는 것은 **환율 조회 한 가지**입니다.

- 보내는 곳: `exchangerate-api.com`
- 보내는 내용: **기준 통화 코드(예: KRW)뿐**
- 보내지 않는 것: 금액, 상호명, 메모, 사진, 위치, 기기 식별자, 그 밖의 어떤 개인 정보도 보내지 않습니다

## 4. 음성 처리

녹음 버튼을 **누르고 있는 동안에만** 마이크가 켜집니다. 손을 떼면 멈춥니다.

말한 내용을 글로 옮기는 일은 **기기가 지원하는 경우 기기 안에서 처리**되며, 이때 음성은 밖으로 나가지 않습니다. 기기가 이를 지원하지 않는 경우에는 iOS의 음성 인식 기능을 통해 Apple의 서버에서 처리될 수 있으며, 그 처리에는 [Apple의 개인정보 정책](https://www.apple.com/legal/privacy/kr/)이 적용됩니다.

## 5. 권한

권한은 그 기능을 쓸 때만 물으며, 허용하지 않아도 나머지 기능은 그대로 쓸 수 있습니다.

| 권한 | 쓰는 곳 |
|---|---|
| 카메라 | 영수증을 바로 찍어 붙일 때 |
| 사진 | 앨범에서 영수증 사진을 고를 때 |
| 위치 | 지출한 곳을 지도에 남길 때 (앱을 쓰는 동안에만) |
| 마이크 | 말로 기록할 때 |
| 음성 인식 | 말한 내용을 글로 옮길 때 |

권한은 언제든 기기의 `설정 → Mission Wallet` 에서 거둘 수 있습니다.

## 6. 광고 · 분석 · 추적

**넣지 않았습니다.** 광고 식별자(IDFA)를 읽지 않고, 분석 도구나 추적 도구를 넣지 않았으며, 제3자에게 정보를 제공하거나 판매하지 않습니다.

## 7. 보관과 삭제

사용자가 지우기 전까지 보관하며, 정해진 보관 기간은 없습니다.

- **하나씩 지우기** — 각 기록의 상세 화면에서
- **모두 지우기** — 앱의 `설정 → 모든 데이터 삭제하기`
- **앱을 지우기** — 기기에 있던 기록이 함께 사라집니다. 다만 iCloud 동기화를 쓰셨다면 iCloud의 사본은 남으므로, 기기의 `설정 → Apple 계정 → iCloud` 에서 따로 지우셔야 합니다

## 8. 아동의 개인정보

만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 알면서 수집하지 않습니다.
